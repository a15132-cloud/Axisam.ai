# Axiscam — frontend

Chat de la Capa 1: React + Vite + TypeScript + Tailwind v4 + Framer Motion + react-three-fiber.

```bash
npm install
npm run dev      # http://localhost:5173, proxy /api -> http://127.0.0.1:8001
npm run build    # type-check + build de producción
```

Requiere el backend (`apps/orchestrator`) corriendo en `:8001`. Ver el README raíz del repo para
el panorama completo y `docs/architecture.md` para el detalle técnico de cada capa.
